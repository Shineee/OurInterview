# Java 冒泡排序

冒泡排序是最直观的交换排序：反复遍历数组，比较相邻元素，把较大者逐步"冒泡"到末端。

## 基本思想

- 从头到尾比较相邻两个元素，若顺序错误（前大后小）则交换。
- 每一轮遍历会把当前未排序区间的最大值交换到末尾，因此第 i 轮之后最后 i 个元素已就位。
- 若某一轮**没有发生任何交换**，说明数组已有序，可提前退出。

## 用 java 实现（带提前退出优化）

```java
public class BubbleSort {
    public static void bubbleSort(int[] a) {
        int n = a.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;          // 本轮是否发生交换
            for (int j = 0; j < n - 1 - i; j++) {
                if (a[j] > a[j + 1]) {        // 相邻比较
                    int t = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = t;
                    swapped = true;
                }
            }
            if (!swapped) {                   // 无交换 => 已有序
                break;
            }
        }
    }

    public static void main(String[] args) {
        int[] a = {54, 6, 3, 78, 34, 12, 45, 56, 100};
        bubbleSort(a);
        for (int v : a) {
            System.out.print(v + " ");        // 3 6 12 34 45 54 56 78 100
        }
    }
}
```

要点：

- 内层上界是 `n - 1 - i`：每轮末尾 i 个已就位，无需再比。
- `swapped` 标志让最好情况提前终止，是面试常提的"优化点"。
- 另一种优化是记录**最后一次交换的位置**作为下一轮内层上界（进一步压缩近有序数组的比较次数）。

## 复杂度与稳定性

| 情况 | 时间复杂度 | 说明 |
| ---- | ---- | ---- |
| 最好（已有序，带标志） | O(n) | 一轮无交换即退出 |
| 平均 | O(n²) | 双重循环 |
| 最坏（逆序） | O(n²) | 每轮都交换 |
| 空间 | O(1) | 原地交换 |
| 稳定性 | **稳定** | 仅相邻且严格大于才交换，相等不换 |

**面试追问：冒泡是稳定的吗？为什么？** → 稳定。相等元素不会交换（条件是 `a[j] > a[j+1]` 而非 `>=`），相对顺序保持不变。

**面试追问：冒泡和选择排序怎么区分？** → 冒泡通过**相邻交换**把大元素逐步后移，交换次数多但每轮确定一个最大值的位置；选择排序每轮**扫描找最小值**后与区间起始交换一次，交换次数少（O(n)）但比较次数同样是 O(n²)。两者平均都 O(n²)，选择排序交换更少、冒泡最好情况可 O(n)。

## 适用场景

- 教学与小数据量（几十个元素）调试。
- 基本不用作生产排序：O(n²) 在大数据下不可接受，实际用 `Arrays.sort`（基本类型双轴快排 / 对象 TimSort）。
- 面试价值在于引出"稳定性、提前退出、交换 vs 选择"这些排序通用概念。

## 【面试追问链】

1. **如何让它在近乎有序时接近 O(n)？** → `swapped` 提前退出 + 记录最后交换位置收缩内层上界；这与插入排序"近有序时快"的性质同类——数据分布影响常数与实际表现。
2. **它和快速排序都是交换排序吗？** → 是，同属交换类；但快排是**跨区间**的分治交换（平均 O(n log n)），冒泡只在相邻间交换，这正是复杂度差异的来源。
3. **能把时间复杂度降到 O(n log n) 吗？** → 不能靠打补丁实现；必须换分治（快排/归并）或选择（堆排）思想。面试官常以此过渡到"排序算法家族全景"。
4. **空间能优化到不用额外变量吗？** → 不行，交换需要临时变量（或位运算异或交换，但可读性差且不解决复杂度问题）。
