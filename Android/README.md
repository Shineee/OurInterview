# 学习路径建议

1. **技术面试 / 笔试**：四大组件、异步、View、库与运行时——应用层完整图景。
2. **Kotlin**：现代 Android 开发语言；协程与 Flow 是异步与状态叙事的主战场。
3. **Java**：存量代码、字节码/ART、并发与 GC 排查的底座；与 Kotlin 协程对照理解线程与内存。
4. **Senior**：系统设计、稳定性、性能、架构演进——把前三块收束成可落地的工程决策与面试叙事。
